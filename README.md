# Pomzv3GV
A group I made originally for my friends but turned into a project I would be doing for 2 years. I enjoy doing this project, and I hope to continue it until I give up. Most of the files linked to this repository are school-related, to find a workaround for playing games, giving links, and more. This repository is currently for playing a variety of HTML games without using blocked CDNs to load the assets. I do not claim to be the owner of the HTML games used in this repository. This is probably my favorite out of all of my repositories because a lot of people liked it. This is very patchable, and I do not claim it to be impossible to patch. The only thing I believe to be hard to patch would be the HTML games used, but it is still possible.
